# DijitalKoku

Görsel içerik analizine dayalı dijital koku eşleme sistemi (V3 — Semantik-Olasılıksal Mimari).

## Kurulum

```bat
install.bat
```

## Çalıştırma

```bat
start.bat
```

Durdurmak için:

```bat
stop.bat
```

## Dokümantasyon

- [PRD V3](PRD_DijitalKoku_V3.md)

## Gereksinimler

Python 3.10+ ve `requirements.txt` içindeki paketler. CUDA destekli GPU için `install.bat` kullanın.
